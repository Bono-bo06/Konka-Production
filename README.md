Project Overview
This project is a 5 page website for Konka Productions, an event production and equipment hire company based in Limpopo. The site shows the equipment we hire out, explains what we do, and lets clients send a quote request straight from the site.

I built the HTML in Part 1. In Part 2 I added an external stylesheet, made the site responsive, and improved the design so it works on phones, tablets, and desktop screens.

Website Goals and Objectives
Goals:

Give Konka Productions a proper online presence.

Show the equipment we hire, like sound, lighting, and DJ gear.

Make it easy for clients to send a quote request.

Look professional and trustworthy.

Objectives:

Get at least 20 quote requests a month.

Let clients browse equipment by category.

Make the site work on any screen size.

Keep load times under three seconds.

Key Features
5 linked pages: Home, About, Services, Request a Quote, Contact.

Semantic HTML5: header, nav, main, section, article, footer.

Only one nav element per page, using a ul and li structure.

Exactly 6 images with descriptive alt text.

Working enquiry form with labels, submit button, and reset button.

Embedded Google Map on the contact page.

Clickable social media links that open in a new tab.

External CSS file linked on every page.

Responsive design with two breakpoints.
Timeline and Milestones
Week 1 and 2: Research and gathering content.

Week 3 and 4: Built the HTML pages and linked them together.

Week 5 and 6: Added CSS, made the site responsive, tested on different screens, and cleaned up the code.

Week 7: Final checks, documentation, and submission.
