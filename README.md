## Project Overview
This project is a 5-page static HTML website for Konka Productions (Pty) Ltd, a professional event production and equipment hire company based in Limpopo. The website serves as an online catalogue and lead-generation tool for customers needing sound, lighting, stage, and DJ equipment for their events.

## Website Goals and Objectives
- Establish a professional online presence for the company.
- Showcase available production equipment and services.
- Generate equipment hire enquiries through a "Request a Quote" form.
- Demonstrate proficiency in HTML5, semantic elements, accessibility, and internal linking.

## Key Features and Functionality
- 5 fully linked HTML pages (`index`, `about`, `services`, `enquiry`, `contact`).
- Semantic HTML5 structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- Single, horizontal main navigation menu (using pure HTML inline tags).
- Exactly 6 placeholder images with descriptive `alt` text.
- Accessible web forms using `<label>`, proper input types (`text`, `email`, `tel`, `date`), a Submit button, and a Reset button.
- Embedded Google Maps `<iframe>` demonstrating location functionality for the head office.
- Clickable social media hyperlinks in the footer.

## Timeline and Milestones
- **Week 1-2:** Research, requirements gathering, and content collection.
- **Week 3-4:** Development of HTML5 structure and content integration for all 5 pages.
- **Week 5-6:** Final testing, internal linking checks, documentation, and submission.
